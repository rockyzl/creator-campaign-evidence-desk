# Campaign Desk design brief

Audience: an operations teammate, or an interviewer, who needs to understand the records before trusting an AI report.
Single job: select a real public campaign, inspect linked content, run an evidence check and review the report.

Mood: daylight studio / production desk. Real thumbnail strips are the signature; the layout groups a source list beside an assistant, not a dashboard of invented KPIs.

Tokens: white #FFFFFF, workspace gray #F1F4F9, ink #152235, marker blue #265DCC, text slate #57677D, amber #8A5713. Pale green denotes returned metadata, amber denotes follow-up; neither means contractual approval.
Typography: Barlow Condensed 600 for the opening and report headings, Manrope for interface text, system monospace only for optional tool details. Mobile collapses the source/assistant columns.

Paper MCP was attempted on 2026-11-16. `create_file` returned a weekly quota limit (reset in four days); no Paper canvas was created. The design was implemented directly and must be checked in a real browser. No source was copied from Postiz or InfluenceX; they informed the workflow research only.
